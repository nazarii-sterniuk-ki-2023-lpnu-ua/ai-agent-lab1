# Архітектура AI-агента (JavaScript, npm scripts, Jest)

## Які проблеми вирішує агент
Агент автоматизує процес створення кросплатформного проєкту (Hello World) мовою JavaScript, налаштування інструментів для збірки та тестування (через npm scripts та Jest), а також генерацію CI/CD конвеєра для GitHub Actions (Windows, Linux, macOS).

## Які skills він використовує
1. **project-scaffold**: створення структури проєкту, базового `package.json`, вихідного коду (Hello World) та `.gitignore`.
2. **build-and-test**: налаштування тестового середовища Jest, створення тестових функцій та команд складання (npm scripts).
3. **github-actions**: генерація файлу `.github/workflows/ci.yml` із матрицею для різних ОС.

## Які commands доступні користувачу
- `git-init`: перевіряє стан репозиторію та оновлює `.gitignore`.
- `create-project`: викликає skill `project-scaffold`.
- `create-build`: викликає skill `build-and-test`.
- `create-actions`: викликає skill `github-actions`.
- `check`: перевіряє структуру, складання, тести та workflow.
- `init`: оркестратор, що послідовно запускає всі попередні команди.

## Які дані передаються між етапами
Команди передають контекст створення файлів: `create-project` формує базовий каталог і `package.json`, які потім доповнюються залежностями на етапі `create-build`. `create-actions` покладається на наявність скриптів `npm test` та `npm start`, згенерованих раніше.

## Як оркестратор обробляє помилки
Оркестратор (`init`) виконує команди послідовно. Якщо будь-який етап завершується з помилкою (наприклад, не вдалося згенерувати код або тести не проходять локальну перевірку), оркестратор зупиняє виконання, щоб запобігти створенню неробочого CI/CD конвеєра, і виводить повідомлення про помилку.
