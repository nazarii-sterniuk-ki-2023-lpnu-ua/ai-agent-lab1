# Проєкт Al-агента для автоматизації розробки (CI/CD)

**Виконав:** студент групи КІ-406 Стернюк Назарій
**Варіант:** 3 (JavaScript, npm scripts, Jest)

## Опис проєкту
Цей репозиторій містить спеціалізованого Al-агента для генерації, складання, тестування і перевірки кросплатформного проєкту Hello World.

## Запуск агента
Для генерації та налаштування проєкту відкрийте GitHub Copilot Chat у VS Code та надішліть наступний запит:

`@workspace Прочитай мій агентський маніфест (.github/agents/build-engineer.agent.md) та виконай команду з файлу prompts/init.prompt.md`

Детальні інструкції щодо запуску локальних тестів та перевірки знаходяться у файлі [docs/usage.md](docs/usage.md).
